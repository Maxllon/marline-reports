# Marline Reports

Материалы отчётов по учебной практике в третьем семестре СПбГУ.

**Тема:** Интеграция и развитие подхода Palantir в системе Marline  
**Автор:** Максим Белимов (Maxllon)  
**Кодовая база:** [Maxllon/marline](https://github.com/Maxllon/marline)

## Структура

| Папка | Содержание |
|---|---|
| `reports/` | Отчёты ([аннотация](reports/annotation.md)) |
| `presentations/` | Презентации |

## Статус

Работа в процессе. Репозиторий создан, материалы добавляются по мере готовности.
